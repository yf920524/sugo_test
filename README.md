# トリリオネアを目指せ！

小学4年生向けの「日本全国を旅する物件買い占め経営ゲーム」です。

**遊んでいたら、いつのまにか日本の地理・産業・文化に詳しくなる**をコンセプトに、
勉強ゲームではなく「日本各地を旅して物件を買収し、街や地方を完全制覇して
巨大企業を作る」ことをゲームとしての面白さの中心に置いています。

北海道・東北・関東・甲信越北陸・東海・近畿・中国・四国・九州・沖縄の全国44都市を
自由に行き来しながら、各都市の名産・産業にちなんだ物件（1都市あたり6〜8件、
1,000万円〜数兆円まで5段階の価格帯、全296件）を買い集め、
**年間収益1兆円（トリリオネア）**を目指します。

## ゲームループ

各都市を自由に移動する → クイズに答える → 物件を買う → 収益を増やす →
都市・地方を完全制覇する → さらに高額な物件や新しい投資先を狙う

- **1ターン＝1か月、4月はじまり**。画面上部に常に「第○期 ○月」を表示します。
- 通常月には物件収益は現金化されません。年間収益は「今の事業規模・次の決算で入る予定の利益」として常時表示され、**3月のターンの直後に必ず「決算」が発生**し、そこで初めて1年分の利益が現金として一気に入金されます（物件基本収益・完全制覇ボーナス・産業コンボ・地方制覇ボーナス・その他ボーナスの内訳つき）。
- 都市の物件を**すべて購入すると「完全制覇」**となり、その都市の収益が2倍になります。
- ある地方（例：関東）に属する全都市を完全制覇すると**「地方完全制覇」**となり、地方全体にさらに収益ボーナスが付きます。
- 特定の物件どうしを買い集めると**「産業コンボ」**が成立し、関連物件の収益にボーナスが付きます（例：静岡の茶畑×茶輸出商社×京都の茶問屋＝お茶産業コンボ）。
- 物件2〜3件を組み合わせる**「産業ミッション」**を達成すると、一度きりの大きな現金報酬がもらえます（コンボと同じ組み合わせでも、ミッションは一度きり・コンボは継続ボーナスと役割が違います）。序盤の2件ミッションは1〜2億円、規模の大きいミッションは数十億〜数百億円と、物件の価格帯に応じて報酬も大きくなります。一部のミッションは達成すると**さらに大きな続編ミッション**が解禁される「連鎖ミッション」になっています（例：お茶産業ミッション達成→お茶産業拡大ミッションが解禁）。
- 移動は双方向・自由。一度通った都市にも何度でも戻れます。分岐点では進む方向を自分で選べます。鉄道・高速道路・（沖縄のみ）空路の路線があり、都市間には道中の密度に応じて臨時収入・出費・クイズ・割引券・決算ボーナスなどの「道中イベント」が発生します（新幹線などの主要幹線は起きにくく、地方路線や海峡・橋・トンネルなどの特別区間は起きやすくなっています）。
- 高額物件の一部は、その都市のクイズに**累計3問正解で大型物件**が、各主要都市の**ランドマーク物件**は**累計10問正解＋通常物件70%以上所有**でアンロックされます（通常物件だけでも進行可能。不正解のペナルティはありません）。
- クイズは「今いる都市 → 同じ都道府県 → 同じ地方 → 全国」の優先順で出題され、一度正解した問題は基本的に繰り返し出題されません。都市ごとの累計正解数に応じて難易度Lv1〜4が徐々に上がり（難しいクイズほどごほうびも大きい）、最初のクイズのあとは「もう1問挑戦」で追加のクイズ（1回の訪問につき最大2回・ごほうび控えめ）にも挑戦できます。物件一覧のロック中の物件からも、その都市のクイズにいつでも挑戦できます。
- 時々「ランダムイベント」（台風・豊作・観光ブームなど）が発生し、その年度の決算に少しだけプラスまたはマイナスの影響を与えます（理不尽な大損失は起きない設計）。
- 序盤は資金繰りに困らないよう、初回都市訪問ボーナス・はじめての物件購入ボーナス・クイズ報酬の割増（最初の6ターン）・「臨時ビジネスチャンス」（どこも買えないときの緊急支援）を用意しています。
- 年間収益が1兆円に到達すると「トリリオネア達成！」。その後も続けて遊び、全物件制覇・全地方制覇・全コンボ達成・全ミッション達成などのコレクションを目指せます。ターン数によるゲームオーバーはありません。

## 遊び方

1. タイトル画面で「はじめから」（セーブがあれば「続きから」も選べます）。
2. 画面中央の方向ボタンをタップすると、サイコロを振ってその方向へ移動します。
3. 到着した都市では「クイズ！」が出題されます（社会科の基本問題が中心）。正解すると現金ボーナス・割引クーポン・決算ボーナスのいずれかがもらえます。時々「ボーナスチャレンジ」で難問に挑戦するかを選べます。
4. 下部の「🏠 物件」でいつでも今いる都市の物件一覧を開いて購入（価格帯タブで絞り込み、購入前後の所持金の変化も確認できます）、「🗺️ マップ」で日本地図の上に配置された都市・路線と全国の完全制覇状況、「🏆 コレクション」で全物件制覇率・ミッション・ランドマーク・コンボの収集状況、「📜 ログ」で移動・購入・決算などの履歴を確認できます。
5. 3月のターンのあとには必ず「決算発表」が入り、1年分の利益が現金に反映されます。

ゲームは自動でセーブされる（各ターン終了時・決算後・物件購入後・アンロック時）ので、ブラウザを閉じてもタイトル画面の「続きから」で再開できます。

## 画面構成

通常のプレイ画面はスクロールせずに1画面で完結する設計です。常に以下を確認できます。

- 現在の年月（第○期○月） / 所持金 / 総資産 / 所有物件数 / 完全制覇都市数
- 年間収益の進捗（年間収益 ○○億円 / 1兆円）
- 現在地と移動先の方向ボタン（路線の種類・道中イベントの起きやすさのヒントつき）

物件一覧・マップ・コレクション・ログ・メニューは、それぞれのボタンを押したときだけモーダルで表示されます。物件一覧は価格帯タブで絞り込むことで、物件数が多い都市でもスクロールなしで確認・購入できます。

## 技術構成

- 100% HTML / CSS / JavaScript（外部ライブラリ・API・サーバー不使用）
- データ・保存処理・ゲームロジックを分離した構成で、都市やクイズの追加がしやすくなっています。
  - `index.html` — 画面構造
  - `style.css` — スマートフォン縦画面優先・ノンスクロールのスタイル
  - `data/cities.js` — 地方（REGIONS）・路線（LINES：鉄道／高速道路／空路・道中イベント密度つき）・都市と物件（CITIES）
  - `data/quiz.js` — クイズバンク（QUIZ_BANK、都市タグ・難易度つき）
  - `data/combos.js` — 産業コンボ定義（COMBOS）
  - `data/events.js` — ランダムイベント定義（EVENTS）
  - `data/tiles.js` — 道中イベント（タイル）の効果カタログ
  - `data/missions.js` — 産業ミッション定義（MISSIONS）
  - `save.js` — セーブ／ロード専用モジュール（今は localStorage を使用）
  - `game.js` — 移動・経済・決算・クイズ・購入・アンロック・演出などのゲームロジック
- 新しい都市・物件・クイズ・コンボ・イベント・ミッションを追加する場合は `data/` 以下に追記するだけで反映されます（`game.js` の変更は不要）。
- セーブ処理は `save.js` に隔離してあるため、将来 Capacitor 等で Android アプリ化する際も `save.js` の中身（`_read`/`_write`/`_remove`）を差し替えるだけで済む構造にしています。
- スマホのChromeでの快適な動作を優先して作成・確認しています。

## GitHub Pagesで公開する方法

1. このリポジトリをGitHubにpushします。
2. GitHubのリポジトリページで **Settings → Pages** を開きます。
3. 「Build and deployment」の「Source」で **Deploy from a branch** を選択します。
4. Branch を公開したいブランチ（例: `main`）、フォルダを **/(root)** に設定して **Save** します。
5. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` でゲームが公開されます。

ビルド処理は不要です。このままpushするだけで公開できます。

## ゲームバランスのメモ

- 初期資金は1億円で、開始直後から複数の物件（1,000万円台）を購入できます。序盤6ターンはクイズ報酬も割増になります。
- 物件は全国44都市・全296件。1都市につき小規模（1,000万〜9,000万円）〜超大型（1,000億円超）まで最大5段階の価格帯を用意しています（都市の規模に応じて6〜8件）。
- 全物件・全都市完全制覇・全地方制覇を達成した場合の理論上の年間収益は約2.8兆円（産業コンボ分を含めるとさらに上がります）。1兆円の目標に対して十分な余裕がありつつ、完全制覇なしでは1兆円到達が難しいバランスにしています。
- クイズの正解報酬（現金・割引・決算ボーナス）、クイズ累計正解によるアンロック、産業コンボ、産業ミッション、地方制覇ボーナスなど複数の攻略ルートに意味があるように設計しており、「高収益率の物件だけを買い続ける」ことが唯一の最適解にはなりません。
- お金の増え方は「毎月の小さなクイズ報酬（都市の累計正解数に応じてLv1〜4に上がり、難しいほど報酬も大きい）」→「産業ミッションによる数か月〜1年に一度の大きな資金」→「3月決算による年1回のまとまった収入」→「完全制覇・産業コンボ・地方制覇による翌年度以降の収益アップ」という階層構造にしており、プレイが進むほど収益の伸び方が加速するようにしています（実測：60ターン=5年分の試遊で年間収益が約9,000万円→約11億円まで、ほぼ毎年1.5〜2倍のペースで増加）。

## 全国マップについて

- 各都市には日本地図上のおおよその座標（`data/cities.js` の `coord`）を持たせており、全国マップはその座標をもとにしたSVGで描画しています。北海道・本州・四国・九州・沖縄のシルエットのヒント（半透明の陸地形状）、実際の路線名がついた鉄道（水色の実線）・高速道路（オレンジの点線）・空路（紫の点線）の接続線、瀬戸大橋・関門海峡・青函トンネルなどの特別区間を示すアイコン、沖縄への「海のギャップ」表現を含みます。都市を格子状・円形などに機械的に並べるのではなく、実際の地理関係を反映した配置にしています。地方ごとのアコーディオン一覧＋主要ルートのテキスト一覧は、SVGマップの下に詳細情報として引き続き表示しています。

## 今回のアップデートで簡略化した点

- 都市間の「道中イベント」は、都市と都市の間に独立したマス（ノード）を配置する方式ではなく、移動区間（路線）ごとの密度に応じて1回だけ判定する方式で実装しています。マス単位での停止・選択はできませんが、「主要幹線は起きにくく、地方路線・特別区間は起きやすい」というルート選択の意味づけは実現しています。
- メイン画面（現在地・方向ボタンのある操作画面）はノンスクロールを厳守していますが、現在地周辺だけを拡大表示する専用のミニマップは今回は見送り、全国マップ（🗺️ボタン）に一本化しています。
