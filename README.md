# にっぽん物件王

小学4年生向けの「社会×物件買い占め」すごろくWebゲームです。

**遊んでいたら、いつのまにか社会科の知識が身につく**をコンセプトに、
勉強ゲームではなく「物件を買い集めて街を独占する」ことを主目的にしています。

東京 → 横浜 → 小田原 → 静岡 → 浜松 → 名古屋 → 京都 → 大阪 をすごろく形式で移動しながら、
各都市の名産・産業にちなんだ物件を購入し、資産を増やしていきます。

## 遊び方

1. 「ゲームスタート」を押すとサイコロ操作画面になります。
2. 「サイコロを振る」をタップして移動します。マスには都市・クイズ・臨時収入・出費・カードなどがあり、内容はランダムです。
3. 都市に着くと、その都市の名産・産業にちなんだ物件（3〜5件）が購入できます。
4. 同じ都市の物件を**すべて購入すると「独占」**となり、その都市の収益（毎ターン自動で入る収入）が2倍になります。
5. 道中では小学4年生レベルの社会科4択クイズが出題されます。正解すると購入資金・割引クーポン・収益ボーナスなどのごほうびがもらえます（不正解でも進行は止まりません）。
6. 大阪に到着するとゲーム終了。現金・所有物件総額・累計収益・独占都市数・クイズ正解数から総合スコアとランクが表示されます。

画面右上の「🗺️ 物件マップ」からは、いつでも全都市・全物件の購入状況を確認できます。

1プレイの目安は5〜10分です。

## 技術構成

- 100% HTML / CSS / JavaScript（外部ライブラリ・API・サーバー不使用）
- ファイル構成:
  - `index.html` — 画面構造
  - `style.css` — スマートフォン縦画面優先のスタイル
  - `data.js` — 都市・物件・クイズ・カードのデータ
  - `game.js` — ゲームロジック
- スマホのChromeでの快適な動作を優先して作成・確認しています。

## GitHub Pagesで公開する方法

1. このリポジトリをGitHubにpushします（このリポジトリはすでにGit管理下にあります）。
2. GitHubのリポジトリページで **Settings → Pages** を開きます。
3. 「Build and deployment」の「Source」で **Deploy from a branch** を選択します。
4. Branch を公開したいブランチ（例: `main`）、フォルダを **/(root)** に設定して **Save** します。
5. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` でゲームが公開されます。

ビルド処理は不要です。`index.html` をルートに置いたままpushするだけで公開できます。

## ローカルで動作確認する方法

ブラウザで `index.html` を直接開くか、簡易サーバーを立てて確認できます。

```bash
npx http-server -p 8080
# ブラウザで http://localhost:8080 を開く
```

## ゲームバランスのメモ

- 初期資金は2,500万円。物件は8都市・全29件、価格帯は200万〜800万円です。
- 所有している物件からは毎ターン自動で収益が入り、独占中の都市は収益2倍になります。
- クイズ正解のごほうび（購入資金・割引クーポン・収益ボーナス）や、カードマスの臨時効果（進む/戻る/もう一度サイコロ/収益ボーナスなど）をうまく使うと、より多くの物件を買い占められます。
