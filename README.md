# トリリオネアを目指せ！

小学4年生向けの「社会×物件買い占め」経営ゲームです。

**遊んでいたら、いつのまにか社会科の知識が身につく**をコンセプトに、
勉強ゲームではなく「日本各地の街を旅して物件を買い占め、資産を増やす」ことを主目的にしています。

東京・横浜・小田原・静岡・浜松・名古屋・京都・大阪を自由に行き来しながら、
各都市の名産・産業にちなんだ物件（1都市あたり8件、1,000万円〜1,000億円超まで5段階の価格帯）を買い集め、
**年間収益1兆円（トリリオネア）**を目指します。

## ゲームループ

各都市を自由に移動する → クイズに答える → 物件を買う → 収益を増やす → 都市を完全制覇する → さらに高額な物件を狙う

- **1ターン＝1か月**。12ターンで1年が経過し、画面上部に常に「○年目○月」を表示します。
- 所有している物件からは毎月、年間収益の12分の1が自動で入金されます。
- 1つの都市の物件を**すべて購入すると「完全制覇」**となり、その都市の収益が2倍になります。
- 移動は双方向で、一度通った街にも何度でも戻れます。分岐がある場合は自分で方向を選べます。
- 高額な物件の一部は、その都市のクイズに**累計3問正解で大型物件、累計5問正解でランドマーク物件**がアンロックされます（通常物件だけでも進行可能）。
- 年間収益が1兆円に到達すると「トリリオネア達成！」でクリア。そのまま続けて遊ぶことも、最初からやり直すこともできます。ターン数によるゲームオーバーはありません。

## 遊び方

1. 「ゲームスタート」を押すとゲーム画面になります。
2. 画面中央の方向ボタンをタップすると、サイコロを振ってその方向へ移動します。
3. 到着した都市では「クイズ！」が出題されます。正解すると現金ボーナス・割引クーポン・収益ブーストのいずれかがもらえます（不正解でも進行は止まりません）。
4. 下部の「🏠 物件」ボタンでいつでも今いる都市の物件一覧を開き、購入できます。
5. 「📜 ログ」で移動・購入・収益の履歴を、「🗺️ 全国マップ」で全都市の物件所有状況を確認できます。
6. 物件を買い占め、都市を完全制覇しながら、年間収益1兆円を目指しましょう。

1プレイは自分のペースで進められます（じっくり遊べば数十分規模の経営シミュレーションです）。

## 画面構成

通常のプレイ画面はスクロールせずに1画面で完結する設計です。常に以下を確認できます。

- 現在の年月 / 所持金 / 総資産 / 所有物件数 / 完全制覇都市数
- 年間収益の進捗（年間収益 ○○億円 / 1兆円）
- 現在地とコンパクトな路線マップ（完全制覇した都市には👑が表示されます）

物件一覧・ログ・全国マップは、それぞれのボタンを押したときだけモーダルで表示されます。

## 技術構成

- 100% HTML / CSS / JavaScript（外部ライブラリ・API・サーバー不使用）
- データとロジックを分離した構成で、都市・物件・クイズの追加がしやすくなっています。
  - `index.html` — 画面構造
  - `style.css` — スマートフォン縦画面優先・ノンスクロールのスタイル
  - `data.js` — 路線（LINES）・都市と物件（CITIES）・クイズ（QUIZ_BANK）のデータ定義
  - `game.js` — 移動・経済・クイズ・購入・演出などのゲームロジック
- 新しい都市やクイズを追加する場合は `data.js` に追記するだけで反映されます（`game.js` の変更は不要）。
- スマホのChromeでの快適な動作を優先して作成・確認しています。

## GitHub Pagesで公開する方法

1. このリポジトリをGitHubにpushします。
2. GitHubのリポジトリページで **Settings → Pages** を開きます。
3. 「Build and deployment」の「Source」で **Deploy from a branch** を選択します。
4. Branch を公開したいブランチ（例: `main`）、フォルダを **/(root)** に設定して **Save** します。
5. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` でゲームが公開されます。

ビルド処理は不要です。`index.html` をルートに置いたままpushするだけで公開できます。

## ゲームバランスのメモ

- 初期資金は3,000万円で、開始直後から最低価格帯（1,000万円台）の物件を購入できます。
- 物件は8都市・全64件。1都市につき小規模（1,000万〜9,000万円）〜超大型（1,000億円超）まで5段階の価格帯を用意しています。
- 全物件・全都市完全制覇を達成した場合の理論上の年間収益は約1.23兆円（1兆円の目標に対して十分な余裕がありつつ、都市の完全制覇なしでは1兆円到達が難しいバランスにしています）。
- クイズの正解報酬（現金・割引・収益ブースト）とクイズ累計正解によるアンロックの両方に価値があるため、「高収益率の物件だけを買い続ける」以外にも複数の攻略ルートがあります。
